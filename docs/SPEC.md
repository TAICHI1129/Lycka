# Lycka Programming Language Specification
**プログラミング言語 Lycka 仕様書**

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 言語名 | Lycka |
| 拡張子 | `.ly` |
| 実行方式 | インタプリタ方式 |
| 開発言語 | Go |

## 2. 言語設計

Lyckaは、演算および条件式を除き、原則としてすべての処理を関数によって実行するプログラミング言語である。

条件分岐などの制御処理についても、専用の構文ではなく関数として提供する。

例えば、条件分岐には `if()` 関数を使用する。

## 3. データ型

Lyckaでは、以下の7種類のデータ型を使用する。

### 3.1. int型

数値を表すデータ型。

例：`1`

### 3.2. list型

複数の値を格納するリスト型。

例：`list[1, 2, 3]`

格納する値のデータ型に制限はなく、異なるデータ型の値を同一のリストに格納できる。

### 3.3. str型

文字および文字列を表すデータ型。

文字列はシングルクォーテーションまたはダブルクォーテーションで囲む。

例：`"A"`、`'B'`、`"AB"`、`'CD'`

### 3.4. cd型

コードを値として扱うためのデータ型。

例：`cd[print(0)]`

`cd[]` はコードを格納するために使用する。

ただし、cd型のみを受け付ける関数の引数においては、`cd[]` を省略できる。

### 3.5. bl型

真偽値を表すデータ型。

以下の2種類の値を持つ。

- `TRUE`
- `FALSE`

### 3.6. null型

無を表すデータ型。

例：`x <- null`

### 3.7. smthng型

具体的な値を特定できない「何か」を表すデータ型。

例えば、以下の演算によって得られた値はsmthng型となる。

`x <- 0 ÷ 0`

smthng型には、以下の特殊な性質がある。

smthng型の値を `x` とした場合、条件式 `x = x` の評価結果は `TRUE` または `FALSE` ではなく、`smthng` となる。

これは、smthng型が特定の値を表すものではなく、具体的に特定できない「何か」を表すものであるためである。

したがって、同一のsmthng型の値同士であっても、その等式が成立するかどうかは判断できない。

## 4. 関数

Lyckaでは、関数によって各種処理を実行する。

以下に、現時点で定義されている関数とその仕様を示す。

### 4.1. print()

**用途：** 値の表示

引数に指定された値を表示する。

対応するデータ型は以下のとおり。

- int型
- str型
- bl型
- list型

### 4.2. if()()

**用途：** 条件分岐

1つ目の引数に指定された条件式の評価結果が `TRUE` である場合、2つ目の引数に指定されたコードを実行する。

2つ目の引数はcd型に対応する。

### 4.3. else()

**用途：** 条件分岐

直近に実行された `if()` 関数の1つ目の引数に指定された条件式の評価結果が `FALSE` である場合、引数に指定されたコードを実行する。

以下の場合、この関数は何も実行しない。

- それ以前に `if()` 関数が実行されていない場合。
- 直近の `if()` 関数の条件式の評価結果が `TRUE` である場合。

引数はcd型に対応する。

### 4.4. isitsth()

**用途：** smthng型の判定

引数に指定された値がsmthng型であるかどうかを判定する。

- smthng型の場合：`TRUE`
- smthng型以外の場合：`FALSE`

戻り値はbl型となる。

すべてのデータ型に対応する。

### 4.5. while()()

**用途：** 繰り返し処理

1つ目の引数に指定された条件式の評価結果が `TRUE` である間、2つ目の引数に指定されたコードを繰り返し実行する。

2つ目の引数はcd型に対応する。

### 4.6. concur()()...

**用途：** 並行・並列実行

すべての引数に指定されたコードを並行実行する。

並列実行が可能な環境では、代わりに並列実行を行う。

引数には2つ以上のコードを指定でき、引数の数に上限はない。

すべての引数はcd型に対応する。

### 4.7. c()...

**用途：** コメント

コメントを記述するための関数。

`c` はcommentの頭文字である。

引数の数に制限はなく、すべてのデータ型に対応する。

コンパイラ内部では、プログラムの実行前に当該関数が削除されるため、実行処理には影響しない。

### 4.8. set()

**用途：** 変数の宣言

引数に指定された文字列と同じ名前の変数を作成する。

ただし、同名の変数が既に存在する場合、新たな変数は作成せず、何も実行しない。

引数はstr型のみに対応する。

### 4.9. to()

**用途：** 変数への代入

直近に実行された `set()` 関数の引数に指定された文字列と同じ名前の変数に、引数に指定された値を代入する。

それ以前に `set()` 関数が実行されていない場合、何も実行しない。

すべてのデータ型に対応する。

## 5. 演算・条件式

以下に、現時点で定義されている演算および条件式の仕様を示す。

### 5.1. 加算演算子（+）

`x + y`

データ型によって、以下の処理を行う。

| データ型 | 処理 |
|---|---|
| int型 | xとyを加算する |
| list型 | xとyに含まれるすべての値を含む新しいlist型の値を生成する。ただし、重複する値は1つにまとめる |
| str型 | xとyの文字列を結合する |
| cd型 | xとyのコードを結合する |
| null型 | null型の値を返す |
| smthng型 | smthng型の値を返す |

bl型には使用できない。

また、異なるデータ型の値を同一の演算式に使用することはできない。

### 5.2. 減算演算子（-）

`x - y`

データ型によって、以下の処理を行う。

| データ型 | 処理 |
|---|---|
| int型 | xからyを減算する |
| list型 | xに含まれる値からyに含まれる値を除いた新しいlist型の値を生成する |
| str型 | xの文字列からyの文字列を除去する |
| null型 | null型の値を返す |
| smthng型 | smthng型の値を返す |

bl型およびcd型には使用できない。

また、異なるデータ型の値を同一の演算式に使用することはできない。

### 5.3. 等価演算子（=）

`x = y`

データ型によって、以下のように評価する。

| データ型 | 評価方法 |
|---|---|
| int型 | xとyが数学的に等式として成立する場合はTRUE、それ以外はFALSE |
| str型 | xとyが一致する場合はTRUE、それ以外はFALSE |
| bl型 | xとyが一致する場合はTRUE、それ以外はFALSE |
| null型 | xとyが一致する場合はTRUE、それ以外はFALSE |
| smthng型 | smthngを返す |
| list型 | 以下のリスト型の比較規則に従う |

cd型には使用できない。

#### 5.3.1. list型とlist型以外のデータ型を比較する場合

比較対象のlist型の値の中に、もう一方の値と一致する値が1つ以上存在する場合は `TRUE` を返す。

一致する値が存在しない場合は `FALSE` を返す。

#### 5.3.2. list型と別のlist型を比較する場合

1つ目のlist型に含まれるすべての値が2つ目のlist型にも含まれており、なおかつ2つ目のlist型に含まれるすべての値が1つ目のlist型にも含まれている場合は `TRUE` を返す。

1つでも含まれていない値がある場合は `FALSE` を返す。

なお、値の順序は比較対象としない。

## 6. エラー

Lyckaでは、エラーを以下の形式で表記する。

`ERROR: エラー名 (エラー固有番号)`

エラーには階層構造を設けることができる。

下位のエラーは、上位のエラーに属する具体的なエラー内容を示す。

例えば、以下のように表記する。

    ERROR: Violated The Function Rule (1)
        Violated The "print" Function Rule (1/1)
            Types That Cannot Be Used (1/1/1)
                "cd" Type Error (1/1/1/cd)

なお、上記のエラー固有番号は仮のものとする。

## 7. 文法

Lyckaでは、原則として関数を上から順番に記述し、記述された順序に従って処理を実行する。

### 7.1. 関数の記述順序

特段の定めがない限り、関数は上から順番に実行される。

複数の関数を記述する場合、それぞれの関数を改行して記述することができる。

また、改行せずに複数の関数を連続して記述することもできる。

例：

`set("x")`

`to(1)`

または、

`set("x") to(1)`

### 7.2. 関数の連続記述

関数は、前の関数の実行後に続けて別の関数を記述できる。

この場合、各関数は記述された順序に従って実行される。

### 7.3. 引数の記述

関数の引数は、関数名の後に続く括弧 `()` 内に記述する。

複数の引数を指定する場合は、括弧を複数記述する。

ただし、関数の仕様によって引数の数および対応するデータ型は異なる。

例：

`concur(print(0))(print(1))`

### 7.4. コードの記述

コードを値として扱う場合は、`cd[]` を使用する。

cd型のみを引数として受け付ける関数では、仕様に従って `cd[]` を省略できる。

### 7.5. 演算・条件式の記述

演算および条件式は、関数とは異なり、演算子を用いて記述する。

演算子の種類や各データ型における処理については、「5. 演算・条件式」に定める。

### 7.6. コメントの記述

コメントには `c()` 関数を使用する。

コメントはプログラムの実行前に削除されるため、実行結果には影響しない。

### 7.7. 直近関数を参照する関数

`else()` 関数が直前の`if()` 関数の結果を参照するような、直近関数の参照は、この2つの関数の間に別の無関係な関数が挟まっていても機能する。
